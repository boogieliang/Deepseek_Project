# 农资 CEO 驾驶舱 · 功能规划与产品方案

> 配套原型：[index.html](index.html)（浏览器直接打开，可切换大区 / 月·季·年）
> 适用范围：肥料、农药、种子、农膜、特肥等农资生产或流通企业（自有品牌 + 经销体系）

---

## 0. 一页结论

农资 CEO 驾驶舱不能做成"通用 BI 换个皮肤"。它必须回答农资老板每天真正睡不着觉的四件事：

1. **钱能不能收回来**（赊销是农资的命门，行业普遍 60%~80% 应收）
2. **货压在哪、什么时候过期**（季节性极强，农药有保质期，压错一个季度就是跌价损失）
3. **渠道是真动销还是假压货**（厂家出货 ≠ 农户使用，渠道库存会反噬）
4. **哪个作物带、哪个产品组合真正赚钱**（不是哪个品类卖得多）

因此建议的骨架是：**"1 个总览 + 4 个作战域 + 1 个智能层"**，12 个必备模块打底，8 个行业专属亮点功能建立壁垒。

## 1. 先看清行业：决定驾驶舱长什么样的 6 个约束

| 约束 | 现实表现 | 对驾驶舱的要求 |
|---|---|---|
| **强季节性** | 春耕（3-4 月）、夏播（6 月）、秋播（9-10 月）三峰，1-2 月几乎停摆 | 所有图表默认带"同比 + 农事窗口"，不能只看环比 |
| **赊销普遍** | 经销商赊销、农户秋后结算，应收账期 3-9 个月 | 回款率、账龄、授信必须是**一级指标**，不是财务附表 |
| **技术服务驱动** | 农户买的是"解决方案"，不是一袋肥 | 服务场次、示范田、测土配方要能归因到复购 |
| **渠道多层级** | 厂家 → 省代 → 县代 → 零售店 → 农户，信息层层衰减 | 必须看**渠道库存 + 终端动销**，只看发货会被"压货式增长"骗 |
| **原料价格波动** | 尿素、磷酸一铵、氯化钾、草甘膦价格年度振幅 20%+ | 采购窗口、锁价建议、成本传导要进驾驶舱 |
| **强监管 + 窜货** | 农药经营许可、肥料登记证；跨区窜货打崩价盘 | 证照到期、一物一码扫码异常要自动预警 |

## 2. 必备基础功能（P0，缺一不可）

### 2.1 经营透视层

**① 经营总览（CEO 首屏）**
- 6 张核心 KPI 卡：销售收入、综合毛利率、回款率、库存周转天数、活跃经销商数、订单履约率
- 每张卡必须有：本期值 / 同比 / 目标差距 / 12 个月迷你趋势
- 一屏之内给出"**今天最该管的 5 件事**"，而不是让 CEO 自己去图里找

**② 品类与单品盈利分析**
- 三维：品类 × 单品 × 区域，看销量、吨毛利、毛利率、费用率
- 关键不是排名，而是**结构**：哪些 SKU 是"走量不赚钱"、哪些是"高毛利但没铺开"
- 必须支持"量-本-利"拆解：原料涨 10%，各产品毛利变动多少

**③ 区域 / 大区作战地图**
- 大区、省、县三级下钻，目标完成率红黄绿
- 结合作物带看：同一产品在蔬菜区 vs 大田区毛利可能差 15pt

**④ 客户与作物结构**
- 按作物（小麦/玉米/水稻/大豆/棉花/蔬菜/果树/马铃薯）看收入与毛利贡献
- 农资的真相：**作物结构决定产品结构**，不是反过来

### 2.2 销售作战层

**⑤ 目标管理与滚动预测**
- 年度目标 → 月度 → 大区 → 业务员，逐级拆解并锁定
- 滚动预测未来 3 个月，自动算"缺口"并给出补缺口路径（新客/复购/提价/新品）

**⑥ 销售漏斗与商机管理**
- 线索 → 意向 → 报价 → 签约 → 发货 → 回款，逐级转化率
- 农资特有环节：**示范田/试验示范 → 观摩会 → 订货会**，要单独成段统计

**⑦ 业务员效能与人效**
- 人均回款、人均服务场次、新增客户数、客户流失率
- 关键设计：**提成与回款挂钩**，不能只挂发货额

**⑧ 价格与促销管理**
- 价盘监控：出厂价、经销商价、零售价三段价差
- 促销活动 ROI（投入费用 / 增量毛利），低于盈亏线自动建议关停
- 返利、搭赠、政策费用率一表看清

### 2.3 渠道与供应链层

**⑨ 经销商 360 视图**
- 基础档案 + 授权区域 + 信用额度 + 进销存 + 返利账户 + 服务记录
- 必须能看"**渠道库存天数**"和"**终端动销率**"，这是识别假繁荣的唯一办法

**⑩ 库存与效期管理**
- 批次级库存，按剩余保质期分档（<45 天 / <90 天 / 正常）
- 效期水位条 + 建议动作（调拨 / 搭赠 / 促销 / 报损）
- 季节性备货模型：结合农事窗口倒推铺货时点

**⑪ 供应链与采购**
- 原料价格指数联动 BOM，测算成本变动
- 缺货预警（按 SKU × 区域 × 时间窗）、到货计划、滞销清理
- 跨仓调拨建议：把临期品从低动销区调到高动销区

### 2.4 资金与风控层

**⑫ 应收与信用管理**
- 账龄四段（0-30 / 31-60 / 61-90 / 90+），逾期率、坏账准备
- 授信额度使用率、超额度客户名单、停货规则
- **一户一策**：逾期天数 → 动作（短信 / 驻点催收 / 停货 / 法务）

**⑬ 风险与合规**
- 证照到期（农药经营许可证、危化品许可、肥料登记证、种子备案）
- 窜货预警、质量投诉、价格倒挂
- 天气灾害预警联动（台风、冻害、干旱 → 灾后补种/补救用药需求）

**⑭ 预警与行动闭环（贯穿所有模块）**
- 每条预警 = 事实 + 影响金额 + 建议动作 + 责任人 + 截止日期
- 支持一键派单到业务员手机，闭环率纳入考核
- 这是驾驶舱和"看板"的分水岭：**没有闭环的看板没人看第二周**

## 3. 指标体系（先定口径，再谈可视化）

**北极星指标建议**：`回款口径毛利额 = 销售收入 × 毛利率 × 回款率`
—— 它同时约束"卖得多、卖得贵、收得回"，避免单纯冲规模。

| 层级 | 指标 | 参考目标 |
|---|---|---|
| 财务 | 收入、毛利率、费用率、经营性现金流 | 毛利 18-22%（复合肥偏低、特肥/农药偏高） |
| 客户 | 回款率、逾期率、客户复购率、活跃经销商数 | 回款率 ≥ 90%，逾期率 ≤ 6% |
| 运营 | 库存周转天数、临期占比、订单履约率、缺货率 | 周转 ≤ 60 天，临期 ≤ 5% |
| 组织 | 人均回款、服务场次、预警闭环率 | 闭环率 ≥ 85% |

> 口径纪律：全公司只能有一套数。收入按含税/不含税、退货冲减、返利计提必须一次定义清楚，否则第一次高管会就会吵起来。

## 4. 亮眼功能：真正能优化农资销售的 8 个差异化能力

这些是通用 BI 做不出来、也最容易在行业内形成口碑的部分。

### ★1 作物-区域-产品 三维毛利地图
- **痛点**：现在按品类看总量，复合肥卖得多但毛利被尿素拖平，没人知道"哪里卖什么最赚钱"。
- **做法**：8 作物 × 6 品类 × 7 大区 = 336 个利润格子，热力图定位最高毛利组合，自动推荐资源倾斜方案。
- **价值**：产品结构优化 1-2 个点，按 8 亿收入测算 ≈ **+1600 万毛利**。
- **难度**：中（需要订单打上"作物"标签，这是最关键的一步数据治理）

### ★2 经销商健康度指数（DHI）+ 动态授信
- **痛点**：只考核进货额，经销商靠压货完成任务，年底渠道库存爆仓、窜货、掉价。
- **做法**：回款率 40% + 动销率 25% + 库存天数 20% + 合规窜货 15% 加权打分，四象限分组（明星/增长但欠款/压货型/危险），分数直接联动信用额度。
- **价值**：提前 2 个月识别衰退经销商；把"压货式增长"换成"动销式增长"。
- **难度**：中（要拿到经销商库存与终端出货数据，通常靠经销商 APP 或返利政策倒逼）

### ★3 农事日历驱动的需求预测
- **痛点**：备货靠经验，早了压库存、晚了错过窗口，一个窗口错过就是一整季。
- **做法**：按作物物候期（返青、抽穗、灌浆、清园、越冬）建立"农事日历"，倒推 30/60 天生成铺货计划、生产计划与促销排期，叠加气象与历史动销做预测。
- **价值**：季节性预测误差可降 25-30%，缺货率与临期率同时下降。
- **难度**：中高（需要农技专家共建日历库，这是护城河也是门槛）

### ★4 赊销风控大脑（含业务员连带）
- **痛点**：赊销是抢市场的武器，也是坏账的源头；业务员为冲量随意放账。
- **做法**：客户风险评分（历史回款、作物价格、经营年限、面积）+ 动态额度 + 逾期自动停货 + 提成与回款挂钩（建议 30% 权重）。
- **价值**：坏账率压降 30%+，现金周转提速，直接改善现金流。
- **难度**：低-中（数据都在自己手里，最快见效，建议**第一个做**）

### ★5 一物一码 · 窜货雷达
- **痛点**：窜货打崩价盘，等业务员发现已经卖了三个月。
- **做法**：箱码-袋码-农户扫码三级关联，扫码地域偏离授权区域自动告警，反查发货批次与经销商链条。
- **价值**：窜货发现从"月级"到"天级"，价盘稳定，经销商信心回升。
- **难度**：中（需要包装赋码改造 + 扫码激励，通常结合"扫码领红包"一起推）

### ★6 原料价格联动与锁价建议
- **痛点**：原料占成本 70-85%，采购时点全凭感觉，涨了拍大腿、跌了压库存。
- **做法**：接入尿素/磷铵/钾肥/草甘膦行情与期货，联动 BOM 与在手库存，输出"现在买 / 再等等 / 分批建仓"的建议和敞口测算。
- **价值**：采购成本降 2-4%，按 5 亿采购额测算 ≈ **1000-2000 万**。
- **难度**：中（行情数据易得，难在把 BOM 和配方管理做准）

### ★7 技术服务转化引擎
- **痛点**：公司养了几十个技术员，说不清他们到底带来多少销售，最后被当成成本中心砍掉。
- **做法**：把服务场次、示范田、测土配方、回访记录与客户复购做归因，算每个技术员的"服务 ROI"和"带货力"，形成可复制的动作模板。
- **价值**：服务 ROI 可量化，复购率 +5-8pt；让"卖方案"替代"拼价格"。
- **难度**：中（需要农技服务 APP 沉淀过程数据）

### ★8 大户 / 合作社 LTV 复购预测
- **痛点**：土地流转加速，千亩大户和合作社占比越来越高，一个客户流失就是几十万。
- **做法**：按面积、作物、历史用药方案、服务记录预测复购概率与流失风险，输出差异化动作清单（框架协议、授信、专属方案、上门服务）。
- **价值**：高价值客户留存率提升，单客年均采购提升 15-20%。
- **难度**：中高（需要客户画像数据积累，建议二期后启动）

### 备选亮点（P2，按需选做）
- **竞品价格情报网**：业务员手机上报终端价，形成区域价差地图
- **天气灾害联动备货**：台风/冻害/干旱预警 → 自动推荐补救方案与备货清单
- **提成模拟器**：CEO 调整政策前先模拟对业务员收入与公司费用的影响
- **示范田数字化**：一块示范田 = 一个内容素材 + 一个转化漏斗
- **AI 经营助手**：自然语言问数（"上周河南复合肥为什么掉量？"），自动拆解到区域/客户/竞品

## 5. 驾驶舱的设计原则（决定它会不会被真正使用）

1. **一屏一结论**：每张图下面必须有一句人话结论，不要让老板自己解读。
2. **异常优先**：默认展示"偏离目标 / 环比突变 / 超阈值"的部分，正常数据折叠。
3. **可下钻**：从大区点到大区，从大区点到县，从县点到客户，最多 3 层。
4. **口径唯一**：所有数字来自同一套指标中台，禁止各系统各算一套。
5. **时效分级**：财务数据 T+1，订单/库存实时，行情 15 分钟，明确标注刷新时间。
6. **移动优先**：CEO 80% 的时间在车上和会上，必须有手机版（至少 KPI + 预警 + 审批）。
7. **行动闭环**：任何异常都能一键派单，且能看到"谁在处理、处理到哪一步"。

## 6. 数据底座与技术架构（务实版）

**四类数据源**
| 类别 | 内容 | 来源 |
|---|---|---|
| 内部交易 | 订单、发货、回款、库存、费用 | ERP（金蝶/用友/SAP）、财务系统 |
| 渠道数据 | 经销商进销存、终端动销、返利 | 经销商 APP / DMS |
| 农户数据 | 扫码、会员、服务记录、示范田 | 一物一码、农技服务 APP、企微 |
| 外部数据 | 原料行情、气象、农产品价格、政策 | 期货/资讯 API、气象 API、农业部 |

**架构建议**
- 层：源系统 → 数据集成（ETL/CDC）→ 指标中台（统一口径）→ 应用层（驾驶舱 + 预警 + 移动端）
- 技术选型：中小体量用 `ClickHouse + Metabase/Superset` 或直接买垂直 SaaS；自研前端 React + ECharts
- 关键：**先建指标字典，再建报表**。80% 失败的 BI 项目死在口径不一致，不是技术

**投入估算（中型农资企业，年收入 5-10 亿）**
- 自研：2-3 名数据/前端 + 1 名业务专家，3-4 个月，一次性 40-80 万，年维护 15 万
- 采购：垂直 SaaS 15-40 万/年 + 实施 10-20 万
- 建议：**先用原型对齐需求，再决定自研还是采购**

## 7. 三期落地路线（12 周可上线一期）

| 期次 | 周期 | 内容 | 交付价值 |
|---|---|---|---|
| **一期：看得见** | 0-4 周 | 打通 ERP/财务/CRM，统一指标口径，上线经营总览 + 应收账龄 + 预警推送 | 高管第一次看到"一套数"，回款风险立刻暴露 |
| **二期：管得住** | 4-10 周 | 经销商 360 + DHI 健康度、库存效期、窜货雷达、业务员效能 | 渠道从"压货"转"动销"，临期损失下降 |
| **三期：算得准** | 10-18 周 | 农事日历预测、原料锁价建议、LTV 复购预测、AI 问数 | 从"看过去"到"算未来"，形成决策闭环 |

**验收标准（建议写进项目合同）**
- 高管周活跃 ≥ 3 次/人
- 预警闭环率 ≥ 85%
- 回款率提升 ≥ 3pt，库存周转缩短 ≥ 8 天，临期损失下降 ≥ 30%
- 月度经营会不再出现"数据对不上"的争论

## 8. 常见坑

1. **做成大屏给参观用**——没有下钻、没有责任人、没有闭环，第二个月就没人打开。
2. **指标太多**——首屏超过 12 个指标，等于没有重点。
3. **忽略赊销**——把应收放在财务附表，是农资驾驶舱最典型的错误。
4. **只看发货不看动销**——渠道库存爆仓时，报表上还是一片繁荣。
5. **数据口径打架**——销售、财务、供应链三套数，会议变成对账会。
6. **一步到位做 AI**——没有干净的主数据和标签体系，预测模型全是垃圾进垃圾出。
